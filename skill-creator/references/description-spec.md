# description 规格

适用环节：环节三（触发描述生成）。输入为环节二确认的需求卡。

## 1. 三段式格式定义

```
[做什么：动词 + 对象 + 可验收产出]
+ [什么时候用：任务场景 + ≥3 条「」用户原话 + ≥1 个可识别对象]
+ [不覆盖什么：排除场景 + 相邻需求归属]
```

| 段 | 必含成分 | 书写格式 | 合格判定 |
| --- | --- | --- | --- |
| 做什么 | 动词、对象、可验收产出 | 「把 [输入] 转成 [输出文件]」「对 [对象] 执行 [动作]，产出 [文件]」 | 动词开头；对象可指认；产出可清点 |
| 什么时候用 | 场景、≥3 条「」原话、≥1 个可识别对象 | 场景句后接「」原话；原话覆盖口语型、术语型、无术语型；对象写扩展名、文件名、命令名或领域术语 | 原话 ≥3 条；三类各 ≥1 条；对象 ≥1 个 |
| 不覆盖什么 | 排除场景、相邻需求归属 | 「不覆盖 [能力或场景]」「不用于 [相邻需求]」 | 排除句含具体对象；相邻需求写明归属 |

整段判定：description 只写调用时机；步骤、能力细节、约束写正文。

## 2. 硬关六项判定表

| 检查项 | 判定标准 | 检查方法 | 不过时退回动作 |
| --- | --- | --- | --- |
| 第三人称 | 叙述部分无第一、第二人称；「」内原话不计 | 去掉「」内容后检索人称词 | 改无主句或第三人称，硬关六项重跑 |
| 长度 | 单行，≤1024 字符 | 字符计数 | 删解释句，留三段与触发语，硬关六项重跑 |
| 原话条数 | ≥3 条，覆盖口语型、术语型、无术语型 | 抽取「」内容逐条计数与分类 | 回需求卡「触发原话」补该类原话，硬关六项重跑 |
| 可识别对象 | ≥1 个：扩展名、文件名、命令名或领域术语 | 全文检索对象形态 | 补对象到「做什么」段，硬关六项重跑 |
| 不做什么 | 含「不覆盖」「不用于」「排除」之一且指向具体能力或场景 | 检索排除句式并读对象 | 回需求卡「不做什么」补，硬关六项重跑 |
| 七个禁词 | 七个禁词零出现；清单见第 3 节 | 全文逐词检索 | 按第 3 节替换写法改写，硬关六项重跑 |

## 4. 三说法测试

| 类型 | 定义 | 来源 |
| --- | --- | --- |
| 口语型 | 生活措辞，可含「技能」 | 需求卡「触发原话」字段，原话不改写 |
| 术语型 | 含 SKILL.md、description、技能名等显式术语 | 同上 |
| 无术语型 | 不提 Skill、技能、description，只描述痛点 | 同上 |

计分：归一化仅保留 CJK 字符与 ASCII 字母数字，字母小写；`coverage = |bigram(说法) ∩ bigram(description)| / |bigram(说法)|`；description 中「」短语为说法子串时按覆盖比例给加成（`bonus = 0.35 × len(触发语)/len(说法)`，封顶 0.35），`得分 = min(1.0, coverage + bonus)`。加成按比例给而非固定值：说法完整等于某条触发语时拿满，只命中长触发语的一小段时折减。

| 得分 | 判定 |
| --- | --- |
| ≥0.30 | 命中 |
| 0.18–0.30 | 边缘 |
| <0.18 | 未命中 |

判定条件：三条全「命中」进入环节四；任一条「边缘」或「未命中」按第 7 节处理。

### 4.1 负样本（误触发检测）

正样本只验「该触发的触发了」，不验「不该触发的没触发」。负样本装的是**相邻需求说法**，取自需求卡「相邻易混淆需求」字段，每条对应一个归属别的技能或场景。

判定：负样本在 description **职责段**（做什么 + 什么时候用）上的纯覆盖率 ≥ 0.40 即判混淆风险，退出码 1，需回环节三补排除场景。

| 纯覆盖率 | 判定 | 处置 |
| --- | --- | --- |
| ≥0.40 | 误触发 | 回环节三补排除场景或收窄可识别对象 |
| 0.30–0.40 | 边缘 | 观察项，交付时写入待确认项 |
| <0.30 | 正常 | 通过 |

判定口径三条：

1. **排除句不计入**。排除句写的是「本技能不做什么」，用来排斥而非吸引；拿它算召回会自相矛盾（排除句里的「账号授权」会抬高「帮我登录这个账号」的得分）。
2. **阈值高于命中阈值 0.30**。负样本与职责段的词面重叠（如「代码质量扫描」与「扫描代码注释」共享「扫描」「代码」）不等于会误触发，需要更高的重叠才判风险。
3. **比较对象是纯覆盖率，不是最终得分**。最终得分含显式触发语加成，正样本常因此拿满 1.0；拿它当基准会让判据退化成永真通过、失去检测力。

负样本清单与正样本清单同放包外 `tests/`。

执行：`python scripts/check_triggers.py --skill [技能目录] --phrasings [说法文件] [--negatives [负样本文件]]`。phrasings 文件每行一条说法，`#` 开头行为类型标签。退出码：正样本全命中且负样本无误触发 0，否则 1。

记录格式（记录放包外 `tests/`，包内不留）：

| 日期 | description 版本号 | 重测原因 | 说法 | 类型 | 命中与否 | 得分 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| [YYYY-MM-DD] | [版本号] | [首次测试 / 补原话 / 改排除场景] | 「[原话]」 | [口语 / 术语 / 无术语] | [命中 / 边缘 / 未命中] | [0–1] | [缺哪类触发语] |

## 5. frontmatter 字段表

| 字段 | 必需性 | 格式 | 不合规处置 |
| --- | --- | --- | --- |
| `name` | 必需 | 小写字母、数字、连字符，≤64 字符，与目录名逐字一致 | 改 name 或目录名，重跑 |
| `description` | 必需 | 单行三段式，≤1024 字符，触发语写在本字段 | 把多语言字段的触发语迁回本字段 |
| `version` | 必需 | 语义化版本 `[主].[次].[修订]` | 补版本号或升位，重跑 |
| `description_zh` / `description_en` | 可选 | 单行展示文案，不承载唯一触发语 | 触发语迁回主 description |
| `display_name` / `display_name_zh` / `display_name_en` | 可选 | 与目标语言匹配，不带版本号 | 按目标语言补展示名 |
| `agent_created` | 可选 | `true` 或 `false` | 与实际创建方式对齐 |

## 6. 多语言规则

| 规则 | 判定条件 |
| --- | --- |
| 主 description 是检索主字段 | 多语言字段只做展示；触发语缺失在主 description 判不通过 |
| 原话各语言各取 | 每种目标语言从该语言用户原话取触发语，不得互译；互译判不通过 |
| 逐语言三说法 | 每种语言口语型、术语型、无术语型各 ≥1 条并逐语言跑测试；缺一类退回环节二补采集 |
| 回译检查 | 多语言展示文案翻译后回译，按对象、动作、边界、术语四类比对差异；触发语丢失、排除场景丢失、超 1024 字符任一出现即重写 |
| 触发语排布 | 主要目标语言在前、次语言在后；不为一种语言牺牲另一种 |

## 7. 失败分支

| 失败情形 | 退回动作 | 重跑范围 | 连续两次不过 |
| --- | --- | --- | --- |
| 硬关某项不过 | 按第 2 节「不过时退回动作」改写 | 硬关六项整体重跑 | 同一问题连续两次不过 → 退回环节二补采集，退回原因写入测试记录 |
| 三说法出现边缘或未命中 | 从需求卡取该类原话补进「」触发语 | 三条说法整体重测 | 同上 |
| 负样本出现误触发 | 补「不覆盖什么」段的排除场景，或收窄可识别对象 | 正负样本整体重测 | 同上 |
| 多语言缺类或回译差异 | 补该语言原话或按差异类别改写 | 该语言三说法重测，回译表重填 | 同上 |
| 触发语只写在多语言字段 | 迁回主 description，多语言字段留展示文案 | 硬关六项 + 三说法整体重跑 | 同上 |
