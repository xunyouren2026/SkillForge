# 结构决策规则（环节四加载）

加载时机：环节四全程加载；环节五核对行数时按第 2 节重算。

## 1 默认最小集格式

```
skill-name/
└── SKILL.md
```

判定：基线只有 `SKILL.md`；新增任何目录为非常规项，逐目录举证。不预建空目录、不留占位文件。

## 2 行数预算计算表

定稿前按段估行，逐项相加。行数区间的取值为合格区间。

| 段落 | 行数区间 | 计算式 |
| --- | --- | --- |
| 目标段 | 12–18 | 目标一句话 + 原则 2–3 条 + 边界清单 |
| 前置段 | 20–30 | 必拿信息表 + 资源索引表 + 运行环境 |
| 步骤段 | 每步 14–22 | 步骤数 × 每步 18 行（四要素各 1 行 + 标题与空行） |
| 输出示例 | 18–28 | 目录树 + 成品片段 + 验收字段 |
| 禁止项与常见错误 | 25–35 | 禁止项 10 条 + 常见错误三栏表 4–6 行 |
| 资源索引 | 8–12 | 每个外置文件 1 行 + 表头；并入前置段时不单加 |
| 合计 | 目标 ≤300，上限 500 | 各段相加；300–500 定位超支段，只外置该段；>500 必须拆分 |

单个 reference 只讲一件事：目标 ≤300 行，上限 500 行。

## 3 三问判定表

按三问逐项判定，答「是」才加对应目录；每加一个目录写一句理由（格式见第 4 节）。

| 判定问题 | 判定标准 | 答「是」加什么 | 答「否」不加 |
| --- | --- | --- | --- |
| 有大量细节用到才读，放主文件会挤占常驻上下文 | 单段内容超过主文件预算 15%，或只在某一步加载 | `references/`，按单主题拆分 | 不加，留主文件 |
| 有确定性操作要可复现 | 同一段逻辑重复写，或结果必须逐次一致 | `scripts/` | 不加 |
| 有要复制填充的模板 | 给产出物复制填充，不是给模型读 | `assets/` | 不加 |

测试资产不参与三问：说法清单、测试报告、回归用例放包外 `tests/`；`examples/` 默认不建。

## 4 理由合格标准

合格格式：

```
[路径] → 不能放主文件的理由 + 加载 / 执行时机
```

合格条件：理由可判定（超过预算 / 需逐次一致 / 需复制填充），且加载或执行时机写到环节或步骤编号。

| 不合格表述 | 判定 | 处置 |
| --- | --- | --- |
| 更规范 | 不合格 | 删除该目录 |
| 惯例 | 不合格 | 删除该目录 |
| 更专业 | 不合格 | 删除该目录 |
| 方便扩展 | 不合格 | 删除该目录 |

理由含上述表述时不构成举证，按「删除该目录，回第 1 节最小集」处置。

## 5 输出格式三块

环节四产出固定三块，缺一块退回环节四起点：

```
skill-name/
├── SKILL.md               # 主流程，预计 [行数] 行
└── references/
    └── [文件名].md         # [用途]，[加载时机]，[超预算段名与行数]
```

| 块 | 必含内容 |
| --- | --- |
| 目录树 | 每个路径一行；`SKILL.md` 行标注预计行数；目录行标注用途 |
| 理由 | 每个非默认目录一行，格式见第 4 节 |
| 行数预算 | 各段行数与合计；目标 ≤300 行、上限 500 行 |

## 6 失败分支表

| 情形 | 退回位置 | 补什么 |
| --- | --- | --- |
| 某目录理由不合格 | 第 1 节最小集 | 删除该目录，重跑第 3 节三问与第 2 节预算 |
| 三项产出缺项 | 第 5 节 | 补目录树、理由或行数预算，重出三块 |
| 行数合计 300–500 | 第 2 节 | 定位超支段，只外置该段并写加载指令，重算合计 |
| 行数合计 >500 | 第 1 节 | 拆出多个单主题 `references/`，重出目录树与预算 |
| 目录树含空目录或占位文件 | 第 5 节 | 删除后重出目录树 |
| 引用路径指向未创建文件 | 第 5 节 | 先建文件再写引用，重出目录树 |
