# 经典力学题解（classical-mechanics-solver）

## 一、目标

把一道经典力学习题转成**可逐步复核**的求解过程，落盘为 `solution.md`：受力图说明 → 方程组 → 符号解 → 量纲与极限检查 → 带单位的数值结果。

三条不可动摇的原则：

1. **符号先于数值**：先写出显式方程组并化简到最简符号形式，再代入数值；禁止一上来就代数字。
2. **每步可复核**：每个方程标注依据（牛顿第二定律 / 约束 / 摩擦定律 / 守恒律），每个数值标注来源。
3. **SI 单位与有效数字**：全程 SI，结果有效数字与题给精度最低量一致（中间值多留 1 位）。

### 适用范围与边界

- **覆盖**：质点与质点系平动、斜面与几何约束、静/动摩擦、弹簧、圆周运动、动量与能量守恒、单自由度简谐振动。
- **不覆盖**：量子力学、相对论力学、连续介质与流体、实验数据拟合、数值仿真（给出替代路径，不硬做）。
- **待用户确认**：刚体转动（涉及转动惯量与力矩）默认不自动展开，列为待确认项。

## 二、前置

### 2.1 输入形式与必确认量

| 项 | 说明 | 缺失时的处理 |
| --- | --- | --- |
| 题干 | 文字题、图片转写、带数值的半结构化描述 | 无法辨识的量保留符号，标注「待确认」 |
| 必确认量 | 质量、角度、摩擦系数、劲度系数、初始条件（位置/速度）、求解目标 | 缺失且影响数值结果 → 先问 1 轮，最多 3 问 |
| 单位 | 统一 SI（kg / m / s / N / rad） | 出现 cm、g、° 时先换算并在解答中写出换算式 |

**禁止臆造题目未给的条件**；可用符号推导并给出「若给定 X，则结果为…」的参数形式。

### 2.2 符号约定

| 符号 | 含义 | 约定 |
| --- | --- | --- |
| `x` | 沿斜面（或选定轴）的位移 | 正方向在 S1 显式声明，全程不变 |
| `N` | 法向约束力 | 垂直于接触面，不做功 |
| `f_s` / `f_k` | 静 / 动摩擦力 | 方向与**相对运动趋势 / 相对运动**相反 |
| `k`, `x_s` | 劲度系数、弹簧形变量 | 弹力写作 `−k·x_s`，与形变量反向 |
| `g` | 重力加速度 | 默认 `9.8 m/s²`，题给其他值时以题为准 |

### 2.3 资源索引（按需加载）

| 文件 | 加载时机 | 作用 |
| --- | --- | --- |
| `references/equation-map.md` | S2 | 题型 → 方程选择表、适用条件、陷阱 |
| `references/checks.md` | S4 | 量纲表、极限情形清单、数量级与符号检查 |
| `scripts/dimensional_check.py` | S4 | 确定性量纲校验，执行即可，不读入上下文 |

运行环境：受管 Python 3.13，脚本仅依赖标准库。

## 三、步骤

### S0　题型识别与闸门

- 输入：题干。
- 动作：判定是否属于「适用范围」；识别题型（平衡 / 恒力加速 / 弹簧振动 / 圆周 / 碰撞守恒）；判定是否需要数值结果。
- 产出：一行题型结论 + 待确认量清单。
- 失败分支：属于不覆盖范围 → 输出边界说明与替代路径，结束；涉及刚体转动 → 列入待确认项，不自行展开。

### S1　建模与受力图

- 输入：题干 + 符号约定。
- 动作：
  1. 选定坐标系并**显式写出正方向**；
  2. 逐一列出全部作用力（重力、法向力、摩擦、弹力、外加力、约束力），逐项说明方向；
  3. 写约束方程（如 `N = mg cosθ`）；
  4. **摩擦方向单独判定**：先假设无摩擦求运动趋势，再令摩擦力反向；静摩擦大小取「维持平衡所需值」，并用 `|f_s| ≤ μ_s N` 检验是否静止。
- 产出：受力图文字说明（含每个力的方向与依据）+ 约束方程。
- 失败分支：趋势与假设矛盾 → 回到本步重新假设，不得直接取 `f_s = μ_s N`。

### S2　建立方程组

- 输入：S1 的受力清单。
- 动作：按 `references/equation-map.md` 选择方程族（牛顿第二定律 / 能量 / 动量 / 角动量），并写明**为什么选这一族**；对每个方向写分量方程。
- 产出：编号方程组，每项标注依据。
- 失败分支：方程数少于未知量数 → 补约束方程或运动学关系，不得凭直觉补数。

### S3　求解（符号 → 数值）

- 输入：方程组 + 题给数值。
- 动作：先解出目标量的符号表达式并化简；再代入数值（写出代入式）；最后按题给最低精度取整，附带单位。
- 产出：符号解 + 数值解（含单位与有效数字）。
- 失败分支：出现多个数学解 → 用物理条件（如 `x ≥ 0`、绳张力非负）筛根，并说明舍根理由。

### S4　校验（不可跳过）

- 输入：方程组与数值解。
- 动作：
  1. 执行 `python scripts/dimensional_check.py`，确认方程各项量纲一致；
  2. 按 `references/checks.md` 做极限情形检查（如 `θ→0`、`μ_k→0`、`k→∞`）；
  3. 检查符号（结果正负是否与 S1 正方向一致）与数量级；
  4. 检查有效数字与单位。
- 产出：四项校验结论，逐条写明「通过 / 不通过 + 依据」。
- 失败分支：任一不通过 → 回到 S1 或 S2，禁止带着不通过项交付。

### S5　输出与交付

- 输入：S1–S4 全部结果。
- 动作：写入 `solution.md`，固定六段结构（见下节），附待确认项；交付文件。
- 产出：`solution.md`。
- 失败分支：待确认量影响结果 → 在文件末尾单列「待确认项」，不擅自补值。

## 四、输出示例（最小交付形态）

```
classical-mechanics-solver/
├── SKILL.md
├── references/
│   ├── equation-map.md
│   └── checks.md
└── scripts/
    └── dimensional_check.py
```

**题**：`m = 2.0 kg` 物块置于 `θ = 30°` 粗糙斜面，经平行斜面的轻弹簧（`k = 120 N/m`）连至斜面顶端固定点，弹簧初始为原长。`μ_s = 0.40`，`μ_k = 0.30`，`g = 9.8 m/s²`。求松开后物块是否运动；若运动，求初始加速度。

`solution.md` 正文：

```
【S0 题型】恒力 + 弹簧的斜面平动；需数值结果。待确认：无。
【S1 受力图】取沿斜面向下为 +x，垂直斜面向外为 +y。
  重力 mg：分量 (mg sinθ, −mg cosθ)
  法向力 N：(+y)，约束方程 N = mg cosθ = 2.0×9.8×cos30° = 16.97 N
  弹簧弹力 −k·x_s：初始 x_s = 0 → 弹力为 0
  摩擦力：先设无摩擦，沿 +x 的驱动力 mg sinθ = 9.80 N > 0
          → 运动趋势沿 +x → 摩擦力沿 −x
  静摩擦上限 f_s,max = μ_s N = 0.40×16.97 = 6.79 N < 9.80 N
          → 静止不成立，物块下滑，改用动摩擦 f_k = μ_k N = 5.09 N
【S2 方程组】(1) m·a = mg sinθ − f_k − k·x_s   [牛顿第二定律 x 分量]
             (2) N = mg cosθ                    [y 向无加速度]
             (3) f_k = μ_k N                    [动摩擦定律]
【S3 求解】符号解 a = [mg sinθ − μ_k mg cosθ − k·x_s] / m
           初始 x_s = 0 → a₀ = g(sinθ − μ_k cosθ)
           = 9.8×(0.500 − 0.30×0.8660) = 9.8×0.2402 = 2.354 → 2.4 m/s²（2 位有效数字）
【S4 校验】量纲：mg sinθ / μ_k N / k·x_s / m·a 均为 M·L·T⁻² → 通过（脚本输出 PASS）
           极限：θ→0 → sinθ−μ_k cosθ = −0.30 < 0，静止判据成立 → 通过
                 μ_k→0，x_s=0 → a₀ = g sinθ = 4.9 m/s² → 通过
           符号：a₀ > 0 与 +x 向下一致 → 通过
           数量级：a₀ < g，合理 → 通过
【结论】物块沿斜面向下滑动，初始加速度 a₀ = 2.4 m/s²（沿斜面向下）。
【附】静止区间：|mg sinθ − k·x_s| ≤ μ_s N → x_s ∈ [0.025, 0.138] m，
      初始 x_s = 0 不在区间内，与「下滑」结论一致。
```

验收条件：`solution.md` 六段齐全；S4 四项校验全部「通过」；每个数值带单位；有效数字与题给精度一致。

## 五、禁止项

1. 跳过 S1 的摩擦方向判定，直接把 `f_s = μ_s N` 当恒等式使用。
2. 在 S2 之前代入数值，或只给数值不给符号方程组。
3. 跳过 S4 量纲检查或极限检查；用「约等于」掩盖有效数字问题。
4. 臆造题目未给的质量、角度、系数或初始条件。
5. 漏列约束力 / 弹力，或把 `N` 写成 `mg` 而非 `mg cosθ`。
6. 混用非 SI 单位（cm、g、km/h）而不写换算式。
7. 对不覆盖的领域（量子 / 相对论 / 仿真）强行给结论。

## 六、常见错误

| 症状 | 根因 | 最小修复 |
| --- | --- | --- |
| 结果比 `g` 还大 | 摩擦力方向取反，或漏掉 `−k·x_s` | 回 S1 重判趋势，回 S2 逐项对数 |
| 该动却判静止 | 把 `f_s,max` 与实际所需静摩擦混淆 | 用 `|f_req| ≤ μ_s N` 判定，而非令 `f_s = μ_s N` |
| 量纲不一致 | 把 `k`（N/m）当 N 用，或漏乘质量 | 跑 `dimensional_check.py`，按量纲表逐项核 |
| 数值差一个 `cosθ` | 法向力写成 `mg` | 回 S1 重写约束方程 |
| 答案符号反了 | S1 正方向与 S2 分量式不一致 | 统一正方向并在受力图首行写明 |
| 有效数字过多 | 直接用计算器全精度 | 按题给最低精度取整，中间值多留 1 位 |
