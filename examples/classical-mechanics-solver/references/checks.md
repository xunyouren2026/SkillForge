# 校验清单（S4 加载）

四项校验缺一不可；任一「不通过」→ 回到 S1 / S2，禁止带病交付。

## 1. 量纲检查

用 SI 基本量纲 `M`（质量）、`L`（长度）、`T`（时间）表示每个量：

| 量 | 量纲 | 说明 |
| --- | --- | --- |
| 质量 `m` | `M` | kg |
| 加速度 `g`, `a` | `L·T⁻²` | m/s² |
| 力 `mg`, `N`, `f`, `kx` | `M·L·T⁻²` | N = kg·m/s² |
| 劲度系数 `k` | `M·T⁻²` | N/m = kg/s² |
| 位移 `x` | `L` | m |
| 角度 `θ`、摩擦系数 `μ`、三角函数 | 无量纲 | — |

规则：**同一方程中每一项的量纲必须相同**，且等号两侧一致。执行 `python scripts/dimensional_check.py` 得到逐项结果。

常见量纲错误：

- 把 `k`（`M·T⁻²`）当力用，忘记乘形变量 `x`；
- 把 `μ N` 写成 `μ m g` 却漏了角度因子（量纲仍对，但物理错 → 靠第 2 项极限检查发现）；
- 把 `m·a` 写成 `m·v`（`M·L·T⁻¹`，量纲不符）。

## 2. 极限情形检查

把参数推到物理上已知的边界，看公式是否退化为已知结论。至少做 2 组。

| 参数极限 | 应满足的已知结论 | 用于发现的错误 |
| --- | --- | --- |
| `θ → 0` | 斜面变水平，重力沿面分量为 0，物块静止 | 漏 `sinθ` / `cosθ` |
| `μ_k → 0` | 无摩擦，`a₀ = g sinθ` | 摩擦项符号取反 |
| `k → 0` | 退化为无弹簧的斜面下滑 | 弹力项方向错误 |
| `m → 0`（或 `m` 消去） | 加速度与质量无关（重力+库仑摩擦系统） | 漏除以 `m` |
| `x_s = 0` | 弹力应为 0 | 把形变量与坐标混淆 |

## 3. 符号与方向检查

1. 结果与 S1 声明的正方向是否一致（正号表示沿正方向）；出现负号必须给出物理解释，不得直接取绝对值。
2. 约束力大小应为正；出现负值说明假设的方向或约束形式有误。
3. 摩擦力方向是否与「运动趋势 / 相对运动」相反。

## 4. 数量级与一致性检查

1. 加速度量级应 ≤ `g` 量级（无外加驱动时）；超出须复核。
2. 静摩擦判据与滑动结论互斥：若判为静止，则不得出现 `f_k`；若判为滑动，则 `|f_req| > μ_s N`。
3. 有效数字：与题给精度最低的量一致；中间值多保留 1 位，最终答案不得多给位数。
4. 单位：每个数值都带单位；同一式中不得混用 SI 与非 SI。

## 5. S4 输出格式

```
【S4 校验】
量纲：mg sinθ / μ_k N / k·x_s / m·a 均为 M·L·T⁻² → 通过（脚本 PASS）
极限：θ→0 → 静止判据成立；μ_k→0 → a₀ = g sinθ → 通过
符号：a₀ > 0 与 +x 向下一致 → 通过
数量级：a₀ < g；有效数字 2 位；单位 m/s² → 通过
```

四项全部「通过」方可进入 S5。
