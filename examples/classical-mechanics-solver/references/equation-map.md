# 题型 → 方程选择表（S2 加载）

## 1. 选择原则

先判断**要求什么量**与**哪些量守恒**，再选方程族。能用一族解决的，不叠加多族；多族并列时必须说明各自独立性与交叉校验方式。

| 题型特征 | 首选方程族 | 选择理由 | 常见陷阱 |
| --- | --- | --- | --- |
| 已知力求加速度 / 求某时刻的力 | 牛顿第二定律分量式 `ΣF_i = m·a_i` | 直接给出瞬时关系，未知量最少 | 漏约束力；正方向与分量符号不一致 |
| 只涉及初末位置与速率，不关心时间 | 机械能守恒 / 功能原理 `W_nc = ΔE` | 消去时间变量，避免解微分方程 | 把摩擦力做功漏掉；把法向力误算做功 |
| 碰撞、冲击、短暂相互作用 | 动量守恒 `Σp_初 = Σp_末` | 内力远大于外力，外力冲量可忽略 | 未判定系统边界；把能量也当守恒 |
| 有固定轴 / 中心力、求角量 | 角动量守恒 `ΣL = const` 或 `τ = I·α` | 力矩为零时角动量守恒 | 转动惯量随位形变化未处理 |
| 弹簧 + 线性回复力 | `m·ẍ + k·x = 0`（或含阻尼/驱动） | 得到解析解与特征频率 | 把弹簧形变量与坐标混用；忽略平衡位置偏移 |
| 静力平衡、求未知约束力 | `ΣF = 0`, `Στ = 0` | 加速度为零，方程降阶 | 静摩擦直接写成 `μ_s N`（错，见下） |

## 2. 摩擦的三条硬规则

1. **方向**：先假设无摩擦求运动趋势，摩擦力与趋势（静止）或与相对运动（滑动）反向。禁止凭直觉设定。
2. **静摩擦大小**：取「维持平衡所需值」`f_req`，判定条件为 `|f_req| ≤ μ_s N`；**静摩擦不是恒等于 `μ_s N`**。
3. **滑动后**：改用 `f_k = μ_k N`，并重新列方程；`μ_k ≤ μ_s` 应成立，否则数据可疑。

## 3. 约束方程速查

| 约束 | 方程 |
| --- | --- |
| 斜面（倾角 θ，无其他 y 向外力） | `N = mg cosθ` |
| 水平面，竖直方向无加速度 | `N = mg` |
| 轻绳 / 轻杆连接两物体 | 沿绳方向加速度分量相等（绳不可伸长） |
| 弹簧（形变量 `x_s`） | 弹力 `−k·x_s`，注意区分自然长度位置与坐标原点 |
| 圆周运动（半径 R，速率 v） | 径向 `ΣF_r = m·v²/R` |

## 4. 何时需要联立

方程数必须 ≥ 未知量数。缺方程时按以下顺序补，禁止凭直觉补数：

1. 几何 / 约束方程（如 `N = mg cosθ`）；
2. 运动学关系（`a = dv/dt`、`v = dx/dt`、绳长约束）；
3. 本构关系（胡克定律、摩擦定律）；
4. 初始 / 边界条件。

## 5. 选用记录格式（写入 `solution.md` 的 S2 段）

```
选中：牛顿第二定律 x 分量
理由：题目要求瞬时加速度，已知全部外力，无须消去时间
未选：能量法（会给位置-速率关系，不直接给 a）
补充方程：N = mg cosθ（y 向约束）
```
