# 线性代数证明核验（linear-algebra-proof-assistant）

## 一、目标

把一条线性代数命题转成**条件完备、可复核**的证明，落盘为 `proof.md`：命题重述 → 定理前提核查表 → 逐步证明 → 反例检索 → 降维验证 → 结论与边界。

三条不可动摇的原则：

1. **前提先于结论**：任何定理在调用前，逐条核对其前提条件；前提未满足即停止，改用构造性论证或给出反例。
2. **每步标注依据**：证明的每一步注明所用定义、引理或定理，禁止「显然」「易得」跳过存在性论证。
3. **必要与充分分开**：明确标注条件是充分、必要还是充要；主动检索「削弱条件后是否仍成立」。

### 适用范围与边界

- **覆盖**：有限维实 / 复向量空间上的矩阵与线性变换；秩、特征值、对角化、正交性、正定性、相似与合同、谱定理、Cayley–Hamilton、Jordan 型的理论证明与前提核查。
- **不覆盖**：数值线性代数计算与算法实现、实分析 / 泛函分析 / 抽象代数的证明、机器形式化验证。这些给替代路径，不硬做。
- **边界说明**：本技能产出的是人类可复核的证明，不等价于形式化证明器已验证的结论。

## 二、前置

### 2.1 输入与必确认量

| 项 | 说明 | 缺失时的处理 |
| --- | --- | --- |
| 命题原文 | 待证命题的准确表述 | 含糊时先重写为「设…，则…」并标注「推断」 |
| 基域 | `ℝ` / `ℂ` / 一般域 `𝔽` | 默认 `ℝ`；涉及复内积须显式确认共轭转置 |
| 矩阵条件 | 方阵 / 对称（`Aᵀ=A`）/ Hermitian（`A*=A`）/ 可逆 / 正定 | 逐项清点，未声明的一律**不默认成立** |
| 允许使用的定理集 | 是否允许谱定理、Jordan 型、Sylvester 惯性定律等 | 未指定时按 `references/theorem-preconditions.md` 全集，并逐条核查前提 |

### 2.2 符号约定

| 符号 | 含义 |
| --- | --- |
| `Aᵀ` / `A*` | 转置 / 共轭转置；`ℝ` 上二者一致 |
| `⟨u,v⟩` | 标准内积（实空间为 `uᵀv`） |
| `Q` | 正交矩阵，`QᵀQ = I` |
| `Λ` | 对角阵 `diag(λ₁,…,λₙ)` |
| `M_n(𝔽)` | `𝔽` 上 `n×n` 方阵全体 |

### 2.3 资源索引（按需加载）

| 文件 | 加载时机 | 作用 |
| --- | --- | --- |
| `references/theorem-preconditions.md` | S1 | 常用定理的前提、结论、常见误用 |
| `references/counterexamples.md` | S2 | 条件削弱后的标准反例库 |

## 三、步骤

### S0　命题解析与条件清点

- 输入：命题原文。
- 动作：改写为「设…，则…」；列出全部显式前提（基域、维数、矩阵性质）；标出结论类型（存在性 / 唯一性 / 等价 / 不等式）。
- 产出：命题重述 + 前提清单 + 结论类型。
- 失败分支：属于不覆盖范围 → 输出边界说明与替代路径，结束；前提含糊 → 标注「推断」并列入待确认项，不擅自补强。

### S1　定理前提核查

- 输入：前提清单 + 拟调用的定理。
- 动作：对 `references/theorem-preconditions.md` 中每个待用定理，逐条核对前提，输出核查表（定理 / 前提 / 是否满足 / 依据）。
- 产出：核查表；**任一前提不满足时禁止调用该定理**。
- 失败分支：无可用定理 → 转构造性证明（极值原理、归纳、分块），不得绕过前提。

### S2　反例检索

- 输入：命题的每个关键条件。
- 动作：按 `references/counterexamples.md` 逐一削弱条件，判断是否仍成立；给出具体小矩阵反例并验算。同时判断条件是否为**必要条件**（存在满足条件之外仍成立的例）。
- 产出：条件可删性表（条件 / 削弱后是否成立 / 反例或说明 / 充分性判定）。
- 失败分支：找不到反例时明确写「未找到反例，但不构成证明」，不臆造反例。

### S3　构造证明

- 输入：核查通过的定理集 + 命题。
- 动作：按「存在性 → 构造 → 归纳 / 推广」组织；每一步标注依据（定义 / 引理 / 定理名 / 上一步结论）；涉及子空间不变性、正交补等结构性步骤必须给出完整推导。
- 产出：逐步编号的证明正文。
- 失败分支：出现循环论证（用待证结论作依据）→ 回 S1 换定理族。

### S4　降维与边界验证

- 输入：证明与结论。
- 动作：取 `n=1`、`n=2` 具体矩阵手工验算；检查退化情形（重特征值、零矩阵、标量矩阵）；检查基域改为 `ℂ` 时表述是否需改为 `A*`。
- 产出：至少 2 组验证记录，逐条写明「一致 / 不一致 + 理由」。
- 失败分支：验算与结论不一致 → 回 S3 复查，禁止交付。

### S5　输出与交付

- 输入：S0–S4 全部结果。
- 动作：写入 `proof.md`，固定六段结构（见下节），末尾列待确认项。
- 产出：`proof.md`。
- 失败分支：待确认的前提影响结论 → 在结论中加限定语，不写成无条件断言。

## 四、输出示例（最小交付形态）

```
linear-algebra-proof-assistant/
├── SKILL.md
└── references/
    ├── theorem-preconditions.md
    └── counterexamples.md
```

**命题**：设 `A ∈ M_n(ℝ)` 且 `Aᵀ = A`（实对称），则存在正交矩阵 `Q` 与实对角阵 `Λ`，使 `QᵀAQ = Λ`。

`proof.md` 正文：

```
【S0 命题重述】设 A 为 n 阶实对称方阵，则 A 可正交对角化。
  显式前提：基域 ℝ；A 为方阵；Aᵀ = A。结论类型：存在性（Q 与 Λ）。
【S1 前提核查】
  谱定理（实对称版）：前提「A 实对称 + 方阵」→ 满足（题给 Aᵀ=A）。
  但为避免循环论证，本证明不直接调用谱定理，改由极值原理构造。
  Weierstrass 定理：前提「紧集上连续函数取最值」→ 满足（ℝⁿ 单位球面 S 紧，f 连续）。
  Lagrange 乘子法：前提「约束梯度非零」→ 满足（∇(xᵀx)=2x，在 S 上 x≠0）。
  归纳法：前提「正交补对 A 不变」→ 需在 S3 第 3 步证明后成立。
【S2 条件可删性】
  删除「对称」：A = [[1,1],[0,1]]，特征值 1（代数重数 2），
      A−I = [[0,1],[0,0]] 秩 1 → 几何重数 1 < 2 → 不可对角化。故「对称」不可删。
  改为 ℂ 上普通对称（Aᵀ=A 但非 A*=A）：需共轭转置条件，结论需改写为 Hermitian 版本。
  反向检查：A = [[1,1],[0,2]] 可对角化但 Aᵀ≠A → 「对称」是充分条件，非必要条件。
【S3 证明】
  1. 令 f(x)=xᵀAx，S={x∈ℝⁿ: ‖x‖=1}。S 紧且 f 连续，由 Weierstrass 定理
     存在 v₁∈S 使 f 取极大值。                                  [依据：紧性]
  2. Lagrange 乘子：∇f=2Ax=2λx（约束 ∇(xᵀx)=2x）→ A v₁ = λ₁ v₁，
     且 λ₁ = v₁ᵀA v₁ ∈ ℝ。故存在实特征值与单位特征向量。        [依据：乘子法]
  3. 令 W={v₁}⊥。对任意 w∈W：
     v₁ᵀAw = (Aᵀv₁)ᵀw = (Av₁)ᵀw = λ₁ v₁ᵀw = 0，
     其中用到 Aᵀ=A。故 Aw∈W，即 W 对 A 不变。                 [依据：对称性]
  4. A|_W 仍对称：∀u,w∈W，⟨Au,w⟩=⟨u,Aᵀw⟩=⟨u,Aw⟩；且 dim W=n−1。
                                                             [依据：内积定义]
  5. 对 dim W 归纳，得 W 的标准正交基 v₂,…,vₙ 及实特征值 λ₂,…,λₙ。
     与 v₁ 合并为 ℝⁿ 的标准正交基。                            [依据：归纳假设]
  6. 取 Q=[v₁ v₂ … vₙ]，则 QᵀQ=I，且 AQ=QΛ，Λ=diag(λ₁,…,λₙ)。
     左乘 Qᵀ 得 QᵀAQ=Λ，λᵢ∈ℝ。∎                              [依据：QᵀQ=I]
【S4 降维验证】
  n=1：A=[a]，取 Q=[1]，Λ=[a] → 一致。
  n=2：A=[[2,1],[1,2]]，v₁=(1,1)/√2 → Av₁=(3,3)/√2=3v₁；
       v₂=(1,−1)/√2 → Av₂=(1,−1)/√2=1·v₂；
       Q=1/√2[[1,1],[1,−1]]，验算 QᵀAQ=diag(3,1) → 一致。
  退化：A=λI 时极大点不唯一，任取标准正交基均可，结论仍成立 → 一致。
  基域：改写为 ℂ 时需以 A*=A 替代 Aᵀ=A → 已在结论中加限定语。
【结论】命题成立（ℝ 上）。「实对称」为充分非必要条件；证明未直接调用谱定理，
       避免循环论证。
【待确认项】无。
```

验收条件：`proof.md` 六段齐全；S1 每个待用定理都有前提核查行；S2 至少给出 1 个具体反例矩阵并验算；S4 至少 2 组降维验证；S3 每步带依据且无循环论证。

## 五、禁止项

1. 未核查前提就调用谱定理、Sylvester 惯性定律、Cayley–Hamilton 或 Jordan 型。
2. 默认「方阵」「可逆」「对称」「特征值互异」成立；题未给即视为不成立。
3. 用「显然」「易得」跳过特征向量 / 基的存在性论证。
4. 循环论证：以待证结论作为证明依据。
5. 混淆相似变换（`P⁻¹AP`）与合同变换（`PᵀAP`），混淆充分条件与必要条件。
6. 把 `ℂ` 上的 Hermitian 结论直接搬到 `ℝ` 或反之而不改写内积与转置。
7. 用数值例子代替证明，或臆造未验算的反例。

## 六、常见错误

| 症状 | 根因 | 最小修复 |
| --- | --- | --- |
| 证明看似完整但循环 | 直接调用谱定理去证谱定理 | 回 S1，改用极值原理 + 归纳的构造性路线 |
| 结论对一般方阵也「成立」 | 漏掉 `Aᵀ=A` 前提 | S2 用 `[[1,1],[0,1]]` 反例拦截 |
| 正交补不变性写不出来 | 忘记用 `Aᵀ=A` 把 `v₁ᵀA` 转为 `(Av₁)ᵀ` | 回 S3 第 3 步补完整等式链 |
| 把充要说成充要 | 未做反向检查 | S2 补「可对角化但不对称」例 |
| 复空间结论符号错 | 用 `ᵀ` 代替 `*` | 回 2.2 符号约定，结论加基域限定 |
| 反例不可信 | 只写矩阵未验算秩 / 特征值 | 在 S2 写出验算式 |
