# 常用定理前提核查表（S1 加载）

使用方法：拟调用某定理时，逐行核对「前提」列；任一不满足即停止调用，转构造性证明或反例。**前提未满足而强行调用，是本技能要拦截的首要错误。**

| 定理 | 前提 | 结论 | 常见误用 |
| --- | --- | --- | --- |
| 谱定理（实对称版） | `A ∈ M_n(ℝ)`，`Aᵀ = A` | 存在正交 `Q` 使 `QᵀAQ` 为实对角阵 | 用于非对称方阵；忘记「正交」而只写「可对角化」 |
| 谱定理（复 Hermitian 版） | `A ∈ M_n(ℂ)`，`A* = A` | 存在酉 `U` 使 `U*AU` 为实对角阵 | 把 `Aᵀ=A` 当作 Hermitian（复情形不成立） |
| 复矩阵可对角化判据 | `A ∈ M_n(ℂ)`，每个特征值的几何重数 = 代数重数 | 存在可逆 `P` 使 `P⁻¹AP` 对角 | 只看「特征值互异」这一充分条件，忽略重根情形 |
| Cayley–Hamilton | `A` 为方阵，`p_A(λ)=det(λI−A)` | `p_A(A)=0` | 用于非方阵；把特征多项式与最小多项式混淆 |
| 秩–零化度定理 | `T: V→W` 线性映射，`V` 有限维 | `dim ker T + dim im T = dim V` | `V` 无限维时套用；把 `rank(A)` 与 `rank(AᵀA)` 混用 |
| Sylvester 惯性定律 | `A` 实对称，合同变换 `PᵀAP`（`P` 可逆） | 正负惯性指数不变 | 把相似变换 `P⁻¹AP` 当合同变换 |
| 正定判据（Sylvester） | `A` **实对称**，且各阶顺序主子式 > 0 | `A` 正定 | 忘记「对称」前提；对非对称矩阵用主子式判正定 |
| 正定的特征值判据 | `A` 实对称（或 Hermitian） | 全部特征值 > 0 ⟺ 正定 | 用于非对称矩阵（特征值可能为复） |
| Schur 分解 | `A ∈ M_n(ℂ)`（任意方阵） | 存在酉 `U` 使 `U*AU` 为上三角 | 误以为可得到对角阵（需正规矩阵 `AA*=A*A`） |
| `AB` 与 `BA` 的特征值 | `A ∈ M_{m×n}`, `B ∈ M_{n×m}` | 非零特征值（含重数）相同 | 忽略零特征值差异；`A`、`B` 非方阵时结论仍成立但不能写成相似 |
| `rank(AB) ≤ min(rank A, rank B)` | 矩阵维度可乘 | 秩上界 | 误写成等式 |
| 谱半径与范数 | 任意方阵 | `ρ(A) ≤ ‖A‖`（任意相容范数） | 把不等式当等式，或要求 `A` 对称 |

## 1. 前提核查表输出格式

```
| 定理 | 前提 | 是否满足 | 依据 |
| 谱定理（实对称） | A 实对称 + 方阵 | ✅ | 题给 Aᵀ=A |
| Weierstrass | 紧集上连续函数 | ✅ | 单位球面紧 |
| 归纳法 | 正交补对 A 不变 | ⏳ 待证 | 需 S3 第 3 步给出 |
```

`⏳ 待证` 的行必须在后续步骤中被证明或撤回，否则不得进入 S3。

## 2. 循环论证检查

若拟调用的定理，其结论就是当前待证命题（或直接等价形式），判定为循环论证：

- 待证「实对称矩阵可正交对角化」→ 不得直接调用谱定理（同一命题）。
- 待证「正定矩阵可逆」→ 可调用「正定 ⇒ 特征值全正」，但需先证该判据本身或援引已建立的引理。

处理：改用更底层的工具（极值原理、归纳、分块、定义展开），并在证明开头注明「为避免循环论证，不直接调用 X」。

## 3. 基域切换规则

| 从 | 到 | 必须改写 |
| --- | --- | --- |
| `ℝ` | `ℂ` | `Aᵀ` → `A*`，正交 `Q` → 酉 `U`，`xᵀy` → `x*y` |
| `ℂ` | `ℝ` | Hermitian → 实对称；特征值仍为实（A*=A 时） |
| 一般域 `𝔽` | — | 不可直接使用「紧性」「极值」「内积」论证；需代数化证明 |
