# 标准反例库（S2 加载）

使用规则：削弱某个条件后，必须给出**具体矩阵并写出验算式**；禁止只写「存在反例」。找不到反例时写「未找到反例，但不构成证明」，不臆造。

## 1. 对角化相关

| 编号 | 削弱的条件 | 矩阵 | 验算 | 结论 |
| --- | --- | --- | --- | --- |
| C1 | 去掉「对称」 | `A = [[1,1],[0,1]]` | `det(λI−A) = (λ−1)²`，代数重数 2；`A−I = [[0,1],[0,0]]` 秩 1 → `dim ker(A−I)=1` → 几何重数 1 < 2 | 不可对角化。「对称」不可删 |
| C2 | 「对称」是否必要 | `A = [[1,1],[0,2]]` | 特征值 1、2 互异 → 可对角化；但 `Aᵀ = [[1,0],[1,2]] ≠ A` | 「对称」是**充分非必要**条件 |
| C3 | 复情形用 `Aᵀ=A` 代替 `A*=A` | `A = [[1, i],[i, 1]]`（`Aᵀ=A`） | `A* = [[1,−i],[−i,1]] ≠ A`；特征值 `1±i` 非实 | 谱定理需 `A*=A` |
| C4 | 「特征值互异」是否必要 | `A = I₂` | 二重特征值 1，但已是对角阵，几何重数 2 | 「互异」是充分非必要 |

## 2. 正定相关

| 编号 | 陷阱 | 矩阵 | 验算 | 结论 |
| --- | --- | --- | --- | --- |
| C5 | 顺序主子式 > 0 但非对称 | `A = [[1, 2],[0, 1]]` | 顺序主子式 `1 > 0`、`det = 1 > 0`；但 `x = (1,−1)ᵀ`: `xᵀAx = 1 − 2 + 0 + 1 = 0`，不正定 | Sylvester 判据**必须**先有对称前提 |
| C6 | 特征值全正但非对称 | `A = [[1, 3],[0, 2]]` | 特征值 1、2 全正；`x=(1,−1)` → `xᵀAx = 1 − 3 + 2 = 0` | 非对称矩阵不能只看特征值判正定 |
| C7 | 半正定与正定 | `A = [[1,0],[0,0]]` | `x=(0,1)` → `xᵀAx = 0` | 半正定 ≠ 正定；不可逆 |

## 3. 秩与乘积

| 编号 | 命题误区 | 反例 | 验算 | 结论 |
| --- | --- | --- | --- | --- |
| C8 | `rank(AB) = rank(A)rank(B)` | `A = [[1,0],[0,0]]`, `B = [[0,0],[0,1]]` | `AB = 0`，`rank(AB)=0`，而 `rank A = rank B = 1` | 只有 `rank(AB) ≤ min(rank A, rank B)` |
| C9 | `AB = BA` | `A = [[0,1],[0,0]]`, `B = [[0,0],[1,0]]` | `AB = [[1,0],[0,0]]`, `BA = [[0,0],[0,1]]` | 矩阵乘法不交换 |
| C10 | `AB` 与 `BA` 全部特征值相同 | `A = [[1,0]]`（1×2）, `B = [[1],[0]]`（2×1） | `AB = [1]`（特征值 1）；`BA = [[1,0],[0,0]]`（特征值 1、0） | 仅**非零**特征值（含重数）相同 |

## 4. 相似与合同

| 编号 | 误区 | 反例 / 说明 | 结论 |
| --- | --- | --- | --- |
| C11 | 相似变换保持对称性 | `P⁻¹AP` 一般不保持 `Aᵀ=A`（除非 `P` 正交） | 对称性由**合同**变换 `PᵀAP` 保持 |
| C12 | 相似 = 合同 | 取非正交可逆 `P`，`P⁻¹AP ≠ PᵀAP` | 二者只在 `P` 正交时重合 |

## 5. 反例检索输出格式

```
条件可删性表
| 条件 | 削弱后是否成立 | 反例 / 说明 | 充分性判定 |
| 实对称 | 否 | C1: [[1,1],[0,1]]，几何重数 1 < 2 | 充分（不可删） |
| 实对称（反向） | — | C2: [[1,1],[0,2]] 可对角化但不对称 | 非必要 |
```

## 6. 验算要求

每个反例必须写出至少一条可手工复核的算式（行列式、秩、特征值、`xᵀAx` 代入值）。仅写出矩阵而不验算的，S2 判为不通过。
