# AI 科研助手

## 一、目标

把一句研究需求转成一份可执行的研究计划，落盘为 `research-plan.md`：研究问题 → 检索策略 → 文献矩阵 → 研究缺口 → 验证方案 → 待确认项。

1. 问题可检验：主问题与子问题都能用一项研究或一组数据回答。
2. 引用可追溯：每条文献带作者、年份、来源标识；无来源的结论不写。
3. 缺口有证据：每个缺口对应矩阵中的一条或多条证据行。

### 适用范围与边界

- 覆盖：文献调研、综述提纲、研究缺口识别、实验或验证方案草案。
- 不覆盖：代写论文正文、伪造数据与引用、代投稿、代码实现与实验执行、伦理审批。
- 待确认：研究伦理边界与数据使用授权在交付时由使用者确认。

## 二、前置

| 项 | 说明 | 缺失时的处理 |
| --- | --- | --- |
| 研究主题 | 一句话方向 + 目标读者或用途 | 缺主题时停止采集，列待确认项 |
| 时间预算 | 调研周期与可用工时 | 未给时取默认两周，标注「推断」 |
| 可用数据与工具 | 可访问的数据库、文献库、实验条件 | 未给时只做方法论建议，不假设可访问 |
| 已有材料 | 已有文献、笔记、初步结果 | 未给时按零基础调研处理 |

运行环境：可读写 Markdown 的编辑器；无脚本依赖；路径以技能根目录为基准。

## 三、步骤

### S1 明确研究问题

- 输入：研究主题、目标读者、时间预算。
- 动作：把主题拆成 1 个主问题与 3–5 个子问题；写研究边界（对象、时间范围、不研究什么）。
- 产出：`research-plan.md` 的研究问题区与边界区。
- 失败分支：主问题过宽或过窄时，列出两个收窄或放宽方案交使用者确认，确认前不进入 S2。

### S2 生成检索策略

- 输入：S1 的研究问题与边界。
- 动作：写检索式（关键词、同义词、布尔组合）、目标数据库、时间范围、纳入标准与排除标准。
- 产出：检索策略表，含检索式、数据库、范围、纳入/排除标准。
- 失败分支：关键词覆盖不足时补同义词并重写检索式，同一检索式最多改两轮；仍不足则标「覆盖有限」进入待确认项。

### S3 筛选与文献矩阵

- 输入：候选文献清单（标题、摘要、元数据）与 S2 的纳入/排除标准。
- 动作：逐条按标准筛入或筛出并记原因；对筛入文献按矩阵字段抽取信息。
- 产出：文献矩阵表，字段固定：编号、作者、年份、研究问题、方法、样本、核心结论、局限、与本研究关系。
- 失败分支：元数据缺失时标「缺」不臆造；无法判断筛入或筛出时进待确认区。

### S4 综述提纲与研究缺口

- 输入：文献矩阵表。
- 动作：按主题聚类；比较方法差异与结论冲突；写争议点；每个缺口标注支撑证据行号。
- 产出：综述提纲（3–6 个主题）+ 研究缺口清单（每条含证据行号）。
- 失败分支：某主题证据不足时标「证据不足」，不给结论；冲突无法解释时列为争议点，不强行调和。

### S5 验证方案草案

- 输入：研究缺口清单与可用数据、工具。
- 动作：每个缺口给一个可验证方案：研究设计、数据来源、指标、对照或基线、风险与替代方案。
- 产出：方案表，缺口编号与方案一一对应。
- 失败分支：方案在当前条件下不可行时，给替代方案并标成本与风险；无可行方案时标「需外部条件」进入待确认项。

### S6 自检与交付

- 输入：`research-plan.md` 全文。
- 动作：核对七项：主问题可检验、检索式可复现、矩阵字段齐全、缺口有证据行号、方案可验证、无占位符、每条引用有来源。
- 产出：交付确认与待确认项清单。
- 失败分支：任一不符时改完重跑自检，不许只改人工项；引用缺失时删结论或补来源。

## 四、输出示例

`research-plan.md` 字段与格式：

| 区块 | 必含字段 |
| --- | --- |
| 研究问题 | 主问题、子问题 3–5 条、研究边界（对象/时间/不研究什么） |
| 检索策略 | 检索式、数据库、时间范围、纳入标准、排除标准 |
| 文献矩阵 | 编号、作者、年份、研究问题、方法、样本、核心结论、局限、与本研究关系 |
| 综述提纲 | 主题 3–6 个、每个主题一句话结论、争议点 |
| 研究缺口 | 缺口编号、缺口描述、证据行号、影响 |
| 验证方案 | 缺口编号、研究设计、数据来源、指标、对照/基线、风险与替代方案 |
| 待确认项 | 确认什么、不确认的后果、当前默认值 |

## 五、禁止项

1. 编造文献、数据或引用。
2. 跳过纳入/排除标准直接写综述。
3. 把推测写成研究结论。
4. 结论不给证据行号。
5. 代写论文正文或代投稿。
6. 伪造实验或调研数据。
7. 超出本技能范围承接代码实现与实验执行。
8. 交付时只说「已完成」，不给 research-plan.md 与待确认项。

## 六、常见错误

| 症状 | 根因 | 最小修复 |
| --- | --- | --- |
| 研究问题过大不可检验 | 未拆子问题与边界 | 回 S1 拆问题并写边界 |
| 综述像文献罗列 | 缺主题聚类与对比 | 回 S4 按主题聚类并写争议点 |
| 缺口没有证据 | 未关联矩阵行号 | 回 S4 给每条缺口补证据行号 |
| 方案无法执行 | 未对照可用数据与工具 | 回 S5 核对条件或给替代方案 |
